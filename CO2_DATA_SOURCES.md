# CO2 Emissions Data Sources

## Overview

The CO2 emissions data in this application has been updated with real-world 2023 data to provide realistic simulation parameters based on actual climate science and carbon budget research.

## Data Sources

### Current Emissions Data (2023)

- **Source**: EDGAR v9.0 database (Emissions Database for Global Atmospheric Research)
- **Reference**: [Our World in Data CO2 emissions](https://ourworldindata.org/co2-emissions)
- **Additional sources**: UNEP Emissions Gap Report 2024, World Population Review

### Global Carbon Budget Constraints

- **Source**: Climate Change Tracker - Indicators of Global Climate Change (IGCC)
- **URL**: https://climatechangetracker.org/igcc/current-remaining-carbon-budget-and-trajectory-till-exhaustion
- **Key Metrics**:
  - Remaining carbon budget for 50% chance of limiting warming to 1.5°C: **130 gigatonnes CO2**
  - Current global emissions rate: **~40 gigatonnes CO2/year**
  - Time to exhaustion at current rate: **~3.25 years** from 2024

- Launch costs funded by Bitcoin seized from violations

### 🎯 Detection Flow Enhancement

1. **Country Exceeds Allowance** → Automatic satellite detection triggered
2. **Satellite Detection Report** → Rich data including:
   - Detected emissions amount
   - Excess over allowance
   - Coverage percentage
   - Number of detecting satellites
3. **Anonymous Verification Vote** → Countries vote "Trust Satellites" vs "Question Data"
4. **66% Trust Threshold** → If reached, enforcement proceeds

### ⚖️ Enhanced Enforcement Options

When satellite detection is confirmed, violating countries get **clear choices**:

#### Option 1: Buy CO2 Certificates

- **Automatic Cost Calculation**: System finds cheapest market offers
- **Affordability Check**: Shows if country can afford purchase
- **One-Click Purchase**: Automated transaction if chosen
- **Immediate Compliance**: Instant CO2 allowance restoration

#### Option 2: Refuse to Buy

- **Warning System**: Clear explanation of consequences
- **Bitcoin Seizure Risk**: Up to 70% of Bitcoin holdings at risk
- **Automatic Tracking**: System monitors continued violations

### 🚨 "Waiting Out" Prevention System

**Automatic Enforcement Trigger**:
Countries that refuse compliance and continue emitting face automatic seizure when:

```
Additional emissions damage + Available Bitcoin ≥ Minimum offset costs
```

**Economic Calculation**:

- **CO2 Damage Rate**: $100 per ton of excess emissions
- **Bitcoin Seizure**: 70% of current holdings
- **Bitcoin Value**: $50,000 per Bitcoin (configurable)
- **Trigger Threshold**: $500,000 minimum intervention value

**Example**:

```
Country refuses compliance → Continues emitting 100 tons → Damage: $10,000
Country has 50 Bitcoin → Seizure potential: 35 Bitcoin → Value: $1,750,000
Total: $1,760,000 ≥ $500,000 → AUTOMATIC SEIZURE TRIGGERED
```
